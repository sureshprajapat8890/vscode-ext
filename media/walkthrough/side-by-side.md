# Compare devices side by side

Run **RN Lens: Open Preview in New Panel** to open a second preview next to the first. With a preview focused, the split icon in its title bar opens the same component again.

Each panel has its own device, orientation, color scheme, platform and lock, so you can watch an iPhone 15 and a Pixel 8 update together on every save. Panels that show the same component share one build, so extra panels cost almost nothing.
